# ⚡ High-Performance SOCKS5 Matrix (Secured Edition)

基于官方 **Gost (v2.11.5)** 核心打造的高性能、轻量化、安全加固版 SOCKS5 代理隧道运维管理系统。

---

## 🌟 核心特性与安全加固

- 🛡️ **纯净安全架构**：
  - **杜绝动态远程命令注入**：移除原版每次输入 `S5` 动态从 Gist 拉取远程未锁定版本代码的隐患，采用本地静态脚本持久化运行。
  - **直连官方源 + SHA256 完整性哈希校验**：彻底移除第三方反代镜像（防止中间人劫持/投毒），全架构（`amd64 / arm64 / armv7 / 386`）内置官方哈希比对。
  - **默认高强度随机安全凭据**：回车默认采用自动生成的强随机用户名与 16 位复杂密码，防止公网弱口令爆破。
  - **严格权限收敛**：配置文件采用 `600` 权限保护，执行脚本采用 `700` 权限隔离。
- 🚀 **系统原生守护**：
  - 支持 **Systemd**（Debian/Ubuntu/CentOS/RHEL/Rocky/Fedora）与 **OpenRC**（Alpine）系统守护进程。
  - 支持开机自启、平滑重启、崩溃自动拉起。
- 🌐 **多源 IP 智能探针**：
  - 自动通过官方多源 API 精准探测服务器外网 IPv4。
- 🧱 **智能防火墙适配**：
  - 自动放行 `iptables`、`ufw`、`firewalld` 对应端口。
- 📟 **现代化 CLI 交互**：
  - 终端输入 `S5` 即可秒级调出彩色可视化管理控制台。

## 📁 目录结构说明

```text
/
├── s5_secured.sh              # SOCKS5 安全加固版一键部署管理脚本
└── README.md                  # 项目说明文档
```

运行安装后，系统内部生成路径：
```text
/etc/socks5_gost.conf          # 代理运行配置文件 (chmod 600)
/usr/local/bin/gost            # Gost 官方官方二进制核心 (通过 SHA256 校验)
/usr/local/share/socks5_matrix.sh  # 本地持久化控制台主脚本 (chmod 700)
/usr/local/bin/S5              # 本地快捷启动命令软链
```

## 🚀 快速开始

### 1. 上传或拉取脚本到服务器
将 `s5_secured.sh` 上传至您的 Linux 服务器（支持 Ubuntu / Debian / CentOS / Alpine 等）。

### 2. 赋予执行权限并安装
```bash
chmod +x s5_secured.sh
./s5_secured.sh
```

### 3. 安装交互提示（支持一路回车）
- **公网 IP**：自动检测，直接回车确认。
- **监听端口**：回车默认使用系统生成的安全随机端口（10000~60000）。
- **代理账号**：回车默认使用生成的随机账号（如 `usr_a1b2c3`）。
- **代理密码**：回车默认使用生成的 16 位高强度复杂随机密码。

## 💡 常用客户端配置格式

- **标准 SOCKS5 URL**：
  ```text
  socks5://用户名:密码@服务器IP:端口
  ```
- **Telegram / 通用代理客户端**：
  - **Server (服务器/主机)**: `你的服务器IP`
  - **Port (端口)**: `配置的端口`
  - **Username (用户名)**: `配置的用户`
  - **Password (密码)**: `配置的密码`

## 🗑️ 彻底卸载

在控制面板中输入 **`8`** 或执行卸载流程，脚本会自动：
1. 终止 Gost 运行进程；
2. 清理 Systemd / OpenRC 系统服务定义；
3. 清除 iptables / ufw 放行规则；
4. 删除 `/usr/local/bin/gost`、`/usr/local/bin/S5` 及配置文件。
