# ⚡ High-Performance SOCKS5 Matrix (Secured Edition)

基于官方 **Gost (v2.11.5)** 核心打造的高性能、轻量化、安全加固版 SOCKS5 代理隧道运维管理系统。

---

## 🌟 核心特性与安全加固

- 🛡️ **纯净安全架构**：
  - **杜绝未授权动态命令注入**：移除每次输入 `S5` 动态从第三方 Gist 拉取未锁定代码的风险，采用本地静态脚本固化运行。
  - **直连官方源 + SHA256 完整性哈希校验**：全架构（`amd64 / arm64 / armv7 / 386`）强制校验官方 SHA256 签名，杜绝中间人劫持或二进制投毒。
  - **默认高强度随机安全凭据**：回车默认采用自动生成的强随机用户名与 16 位复杂密码，防止公网弱口令爆破。
  - **严格权限收敛**：配置文件采用 `600` 权限保护，执行脚本采用 `700` 权限隔离。
- 🚀 **系统原生守护**：
  - 支持 **Systemd**（Debian/Ubuntu/CentOS/RHEL/Rocky/Fedora）与 **OpenRC**（Alpine）系统守护进程。
  - 支持开机自启、平滑重启、崩溃自动拉起。
- 🌐 **多源 IP 智能探针**：
  - 自动通过官方多源 API 精准探测服务器外网 IPv4。
- 🧱 **智能防火墙适配**：
  - 自动放行 `iptables`、`ufw`、`firewalld` 对应端口。
- 📟 **现代化 CLI 交互**：
  - 终端输入 `S5` 即可秒级调出彩色可视化管理控制台。

---

## 🚀 一键在线安装

在 Linux 服务器（支持 Ubuntu / Debian / CentOS / RHEL / Alpine 等）终端中直接运行以下命令即可：

```bash
curl -fsSL https://raw.githubusercontent.com/4kercc/socks5-manager/main/s5_secured.sh -o /tmp/s5.sh && bash /tmp/s5.sh
```

> **提示**：安装交互时支持**一路直接按回车（Enter）**，系统将自动绑定公网 IP 并生成高强度随机端口、随机用户名与 16 位复杂随机密码。

## 📁 系统文件结构

```text
/etc/socks5_gost.conf              # 代理运行配置文件 (chmod 600)
/usr/local/bin/gost                # Gost 官方官方二进制核心 (通过 SHA256 校验)
/usr/local/share/socks5_matrix.sh  # 本地持久化控制台主脚本 (chmod 700)
/usr/local/bin/S5                  # 本地快捷启动命令软链
```

## 💡 客户端快速连接配置

- **标准 SOCKS5 URL**：
  ```text
  socks5://用户名:密码@服务器IP:端口
  ```
- **Telegram / 通用代理客户端**：
  - **Server (服务器/主机)**: `你的服务器IP`
  - **Port (端口)**: `配置的端口`
  - **Username (用户名)**: `配置的用户`
  - **Password (密码)**: `配置的密码`

## 🗑️ 彻底卸载

在控制台输入 **`9`** 即可彻底清理服务、开机自启项、防火墙端口放行规则以及二进制文件。
